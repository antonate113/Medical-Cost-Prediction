# Medical Cost Prediction

## Project Overview
This project aims to predict individual medical insurance costs using Machine Learning regression algorithms.

The model will analyze personal and lifestyle characteristics to estimate insurance charges.

## Dataset Features
- Age
- Sex
- BMI
- Number of Children
- Smoking Status
- Region
- Insurance Charges (Target Variable)

## Technologies & Libraries
- Python
- NumPy
- Pandas
- Matplotlib

- Scikit-learn
